项目说明

① 统一响应格式

所有接口返回 { "code": 0, "msg": "提示信息", "data": {...} }，code=0 为成功，非 0 为失败。

② 命名规范

CSS 类名、JS 变量与函数、数据库表及字段统一以 Cheney_ 开头，便于检索与批改。

③ 记录文件

Cheney_prompt.md（提示词）、backend/Cheney_interface.md（接口）、backend/Cheney_database.md（建库 SQL）均只追加不覆盖。

④ 启动方式

双击根目录 启动项目.bat，后端在 115 端口同时托管前端页面与 /api 接口。
